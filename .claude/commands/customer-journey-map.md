# Customer Journey Map Skill

## Context: Radar (Market Analyzer)
Radar is a Vite+React SPA used by Yektanet sales managers to analyze advertiser CSV data — viewing spend trends, market share heatmaps, industry breakdowns, and AI chat insights.

## Customer Journey Map Framework

This methodology documents customer interactions across five stages along six dimensions to create cross-functional alignment and surface experience pain points.

### Five Stages
1. **Awareness** — How users first encounter Radar
2. **Consideration** — How they evaluate whether to use it
3. **Decision** — Committing to use Radar for a task
4. **Service** — Active usage of Radar's features
5. **Loyalty** — Returning usage and advocacy

### Six Dimensions per Stage
- **Customer Actions** — Observable behaviors
- **Touchpoints** — Where/how interactions occur
- **Customer Experience** — Emotions and thoughts
- **KPIs** — Measurable success indicators
- **Business Goals** — Intended outcomes
- **Teams Involved** — Cross-functional ownership

### Critical Success Factors
- Create separate maps for different personas
- Ground assumptions in analytics and observation
- Revisit quarterly as behavior evolves
- Capture specific emotions, not generic ones ("overwhelmed by data" not "confused")

### Common Mistakes
Generic emotions, missing touchpoints, mapping desires not actual behavior, omitting metrics, treating as one-time exercise.

## Your Task
Map the daily journey of a Yektanet sales manager using Radar. Cover:
1. Morning: opens Radar, uploads new CSV data
2. Analysis: reviews trends, heatmap, industry breakdown
3. Insight: uses AI chat to answer a specific question
4. Action: exports data or saves a report for a client call
5. Follow-up: reviews saved reports, tracks changes over time

For each stage document all six dimensions. Highlight the top 3 pain points with measurable improvement opportunities.

Save output to `docs/customer-journey-map.md`.
