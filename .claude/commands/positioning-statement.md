# Positioning Statement Skill

## Context: Radar (Market Analyzer)
Radar is a Vite+React SPA used by Yektanet sales managers to analyze advertiser CSV data — viewing spend trends, market share heatmaps, industry breakdowns, and AI chat insights. It is an internal tool for Yektanet (Iranian ad-tech company).

## Geoffrey Moore Positioning Statement Framework

### Core Structure
```
Value Proposition:
"For [target], that need [underserved need], [product] is a [category] that [benefit]"

Differentiation Statement:
"Unlike [competitor], [product] provides [unique differentiation]"
```

### Key Purpose
Forces hard choices about target, need, and differentiation. Exposes weak positioning by requiring specificity over generic claims.

### Critical Quality Checks
- Outcome-focused language over features ("reduces time-to-insight by 60%" > "has analytics")
- Name real competitors (Excel, manual reports, generic BI tools)
- Specific target audience, not "everyone"
- Defensible differentiation, not aspirational

### Common Failure Modes
- Overly broad targeting ("for all Yektanet employees")
- Feature-listing instead of benefit-stating
- Positioning against imaginary competitors
- Unsubstantiated claims
- Unclear product category

### When to Apply
Defining new products/pivots, aligning internal stakeholders, testing defensibility of differentiation.

## Your Task
Write a positioning statement for Radar. Consider:

**Target:** Yektanet sales managers and team leads
**Category:** Internal market intelligence tool / sales enablement platform
**Competitors to consider:** Manual Excel analysis, generic BI dashboards (Tableau, Power BI), CRM reports, ad-hoc data pulls from engineering

For each positioning statement:
1. Write the value proposition sentence
2. Write the differentiation statement
3. Evaluate: is the differentiation defensible or aspirational?
4. Identify one claim that needs data to substantiate

Write 2 versions: one for sales managers (daily users), one for Yektanet leadership (decision-makers).
