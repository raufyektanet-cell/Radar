# Problem Statement Skill

## Context: Radar (Market Analyzer)
Radar is a Vite+React SPA used by Yektanet sales managers to analyze advertiser CSV data — viewing spend trends, market share heatmaps, industry breakdowns, and AI chat insights.

## Problem Statement Framework

Use this empathy-driven framework to align stakeholders around validated user problems before solutioning begins.

### Core Framework
```
I am: [Persona description]
Trying to: [Desired outcomes — not tasks]
But: [Barriers blocking outcomes]
Because: [Root cause, not symptom]
Which makes me feel: [Emotional impact — research-backed]
```

### Critical Success Factors
- Gather evidence from user observation before writing
- Be specific in persona definition (avoid generic descriptors)
- Focus on outcomes, not tasks, in the "trying to" section
- Identify root cause, not symptom, in the "because" section
- Use authentic emotions grounded in observed behavior

### Anti-Patterns to Avoid
- Solution smuggling (framing features as problems)
- Business metrics presented as user problems
- Generic personas lacking specificity
- Symptoms mistaken for root causes
- Manufactured emotions

### When to Apply
Use for discovery kickoffs, stakeholder alignment, and feature request validation.
